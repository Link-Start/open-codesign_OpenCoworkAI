## Public wire and coherence

`session.captureFacts({targets:[{key:'t0',locator:{by:'form-control-label',label:'Public label',exact:true,within:{by:'role',role:'group',name:'Public group',exact:true}}}],includeDocument:true})`.

- Only targets/includeDocument; target only opaque public alias key and locator. No private key, expected, comparator, baseline, source, selector, callback or script. Recursive locator allowlist is cloned/frozen, bounded depth and 100-target cap. `by:'role',role,name?,exact?,within?` and `by:'form-control-label',label,exact?,within?` are supported. Exact defaults true; explicit false is normalized substring matching, not first-match selection. Legacy `by:'text'` remains explicit compatibility, not a hidden pilot requirement. query-ref resolution/cycle checks happen in evaluator's public catalog before this wire.
- Form-label selection uses native input/textarea/select or semantic input roles including spinbutton, textbox, searchbox, combobox, checkbox, radio, slider; an unspecified public input type is not secretly restricted to textbox. Mixed same-label controls remain ambiguous. Hidden/ineligible are not silently selected; unsupported values never become empty.
- Every compound sample uses **one DOMSnapshot.captureSnapshot** for all node geometry, computed CSS, text, native value channels, DOM tree order and document content extents. AX is captured before/after, solely to resolve semantic nodes and validate role/name/value/properties and outer-to-inner context IDs. A changed target/context/frame/AX state is unknown. Page CSS viewport metrics are bracketed and must agree, including offsets matching the snapshot's scroll offsets.
- This is coherent single-layout-response acquisition, **not a claim AX/layout are atomic**. Evidence has singleSnapshot, axBracketStable, complete monotonic captureSpan and raw native artifact path. Sample ID is only evidence, never stable identity.
- Identity includes renderId, renderEpoch, viewportEpoch, actual viewport, frameId, opaque target keys, locator digests, backend IDs and context chains. `evidence.geometryVector` contains every requested visible target x/y/width/height plus native document dimensions/viewport/scroll. Evaluator must use the complete vector for stability, not merely a scalar projection. R/G share this one trajectory and one outer deadline, then project offline in Node.

Each target has status unique/ambiguous/not-found, matchCount, backendNodeIds, contextBackendNodeIds and **nodes** (not elements). Each node provides backendNodeId/documentIndex/nodeIndex/parentBackendNodeId/ancestorBackendNodeIds, boundingRect `{x,y,width,height,w,h}` in document CSS coordinates, visible/text/value/valueState/valueError/rawPresence/attributes/enabled, role/name/AX properties, raw `computed` kebab-case properties, camelCase `computedStyle`, and native ancestor `layoutContexts`. valueState is the compatible available/unavailable/unsupported string; r3 valueCollector adapts it to the typed measurer envelope. ## Pilot user-visible domain derivations (pure Node, no expectations)

1. `deriveBoxGapFacts(capture,{fromKey,toKey,axis:'horizontal'|'vertical'})` → facts.separationPx. Positive = physical clear interval between the two visible border-box intervals, negative = overlap; independent of query order. `fromToSignedPx` separately preserves directional displacement. It reports both boxes, common native layout context and raw CSS row/column gap **separately**. CSS gap, margins, space-between and transforms are not confused with actual visible gap. Percentage CSS gaps can still have directly measurable visible box separation; no percentage-to-px guess is used.
2. `deriveVisualGridFacts(capture,{itemKeys,gridClusterTolerancePx})` → columnCount/rowCount, columns/rows and per-key positions/boxes. Sort physical left/top edges; greedy complete-link clusters have max-min <= fixed public tolerance (no transitive chaining). Flex, block and grid are all valid implementations. Native CSS grid tracks are diagnostics, not an eligibility restriction or a substitute for visual clustering. Tolerance is frozen public probe data, never adjusted to expectations/results.
3. `deriveQueryOrderFacts(capture,{itemKeys,orderBasis:'visual'|'dom'})` → orderedKeys. DOM uses same-document native documentIndex/nodeIndex. Visual means physical top-to-bottom then left-to-right, with fixed 0.5 CSS px complete-link row grouping. Indeterminate coincident x/y within 0.5 yields unknown rather than inventing visual order from the request. Both DOM and visual arrays/context/boxes are retained. RTL/flex-reverse differences are factual and tested; this physical convention must be accepted by the protocol/evaluator, not silently changed to an expected order.
4. `deriveDocumentOverflowFacts(capture)` → horizontalPx/verticalPx = max(0, native document content extent minus actual layout viewport). Internal scrolling/clipping does not become document overflow. `targets:[]` supports automatic checkpoints. Missing native dimensions = unknown, not zero.

These functions return `{state:'ok',facts}` or structured unknown. They do not receive comparators/expected/baselines. CSS-specific diagnostics remain separately named `deriveGapFacts` (actual computed CSS gaps plus optional signed box distances), `deriveGridFacts` (browser-resolved CSS used tracks/placement declarations), `deriveOrderFacts` (DOM/CSS-order-modified/physical x/y). **Do not use CSS-only derivers as the pilot visual endpoints.** Unresolved percentage CSS gap or subgrid track spelling can be unknown for the CSS diagnostic while the visual endpoint remains measurable from native boxes plus layout context.

## Scene actions and lifecycle

- `setViewport({width,height,state:'preserve'})`: no remount/reset; same live document, DOM backend IDs and React mount. renderEpoch unchanged, viewportEpoch increments before transition. Old viewport observations are invalidated. CSS/media and source resize handlers still execute and can change application values; observer does not claim arbitrary source cannot mutate state. Node checks business-state preservation. Scroll may be retained or clamped.
- `reload({state:'reset-to-source',artifactId?})`: executes the **last successfully rendered bytes**, including a patched candidate, not a research-baseline revert. Fresh owned browser/document/profile and React/business state, scroll reset; new renderEpoch and viewportEpoch, current viewport retained. No arbitrary replacement source accepted by reload.
- Replay/state changes are explicit actions, never hidden observation retries. In-flight viewport failures invalidate and clean the session. Single-flight cleanup and render/viewport epoch transport guards remain.
