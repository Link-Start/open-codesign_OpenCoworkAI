## 1. Statistical contract fixed at the independent boundary

Implements `statistical-analysis-v1.md` §2 and checks against the independent `auditInput` implementation using handwritten synthetic receipts.

```js
const analysis = toAnalysisInputV1({
  experiment, design, evaluationBinding?, costEvents: []
});
// evaluationBinding is supplied by independent evaluation owner, never generated by converter:
{ evaluationSchema: 'frozen raw schema', normalizerVersion: 'independent revision' }
```

The root binding is required through `experiment.evaluationBinding` or the explicit argument; when both exist they must match. `design.maxBriefsPerCluster` is a **required pre-outcome positive safe-integer frame bound**. Conversion verifies observed family sizes do not exceed it, but does not replace it with the observed maximum or infer missing values. A frozen bound of 2 remains 2 even when the observed maximum is 1. This numerical check does not prove the bound was genuinely preregistered; independent sampling owner must attest the provenance.

Every accepted eligible endpoint requires an independently normalized outcome. A naked local runner `{outcome:'S',uncertainty:false}` is insufficient and is rejected. The normalizer supplies all three booleans, binding versions, the existing SHA256 evidence hash and exact classification. The converter copies/validates but **never calculates, fills or guesses `evidenceHash`**.

Canonical classification spelling matches statistics: **`S`, `W`, `U_A`**. `UA` is not silently aliased. `allRequiredPassed=true` is incompatible with either confirmed violation or unknown. W may coexist with unknown. With no violation, unknown means U_A. All three booleans false is invalid. Independent classification and unknown must also agree with the runner's complete-key summary; disagreement is an audit error, not an instruction to overwrite the independent owner.

Only permitted design fields and permitted normalized outcome/binding fields enter analysis JSON. Source/patch, raw receipt, private expected values, unknown design metadata, and extra binding fields do not. This is a statistical input projection, not permission to publish the resulting opaque IDs; the full ledger and analysis stay with independent owner until authorized release.

## 2. Compatible injected evaluator envelope

The existing runner receives this optional additional envelope alongside its existing per-endpoint key/status rows:

```js
{
  R: [{key, status:'pass'|'confirmed-violation'|'unknown'|'notMeasured'}],
  G: [/*same public row-state protocol, independent private expected stays hidden*/],
  independentEvaluation: {
    evaluationBinding: {evaluationSchema, normalizerVersion},
    outcomes: {
      R: {
        confirmedViolation, unknown, allRequiredPassed,
        binding: {evaluationSchema, normalizerVersion, evidenceHash, classification:'S'|'W'|'U_A'}
      },
      G: null // or independent r3 ineligible bound all-false/classification:null object; analysis masks it to null
    },
    receipt: /*unchanged JSON-compatible raw independent receipt or content-addressed storage reference*/
  }
}
```

`runExperimentV1({...,evaluationBinding})` snapshots the root before execution. The independent envelope is deep-cloned/frozen and preserved verbatim at `record.independentEvaluation`; row summarization does not erase it. Strings preserve serialized bytes (`bytesUtf8`) when the owner chooses that form; raw binary/typed arrays are not the JSON ledger interface and must live in independent evidence storage with a reference. Tests confirm later caller mutation cannot alter the saved receipt. The analysis projection deliberately omits raw receipt content while copying its already-supplied hash binding unchanged.

The converter does not claim a syntactically valid 64-hex value proves the raw receipt authentic. Canonical serialization, raw byte storage, hash verification and normalizer version/code identity remain independent evidence-auditor responsibilities. A method-provided result cannot serve as this independent envelope. If runtime/evaluator is missing, failed, or returns only old row arrays, the runner still preserves accepted/UA accounting, **but conversion for scientific analysis fails closed without independent normalization/binding**. This avoids inventing evidence for unmeasured accepted slots; an independent owner must issue an authentic notMeasured receipt if that is the terminal condition.

## 3. Decision lock compatibility correction

Older method-runner code used `acceptanceLocked=true` for every invoked terminal decision, including rejection. That differs from the final statistics contract. This revision separates:

- `decisionLocked=true`: an invoked decision has become immutable (including reject/error).
- `acceptanceLocked=true`: only an actual accepted candidate was locked before private execution/evaluation.
- Nonaccepted records have `acceptanceLocked=false`; conversion refuses contrary old records rather than rewriting history.

`scopeGuardRejected` in analysis is true only for **FULL** methodRejection with the specific `scope-unsupported` guard reason. PROVENANCE_OFF may independently reject for scope but is not labelled the FULL-versus-OFF scope contrast. Earlier 48-test receipt and its artifact hashes remain historical evidence, not claims about revised bytes.

## 4. r3 independent bridge: required exact owner answers

Proposed upstream API from parent (not yet implemented/certified here):

```js
captureBaselineR3({originalRenderRequest,plan,sessionFactory,calibration,environment,policy})
  -> baselineBundle // opaque to methods; eligibility decided before proposal

evaluateAcceptedR3({candidateRenderRequest,originalSourceSha256,baselineBundle,
  acceptanceLock,plan,sessionFactory,calibration,environment,policy})
  -> {schemaVersion,originalSourceSha256,candidateSourceSha256,acceptanceLockId,
      endpoints:{R:{eligibility,classification,reasons,uncertainty},G:...},
      expectedKeys,checks,provenance}
```

The new bridge should belong to the independent evaluator/execution boundary, with private plan/baseline/expected in its closure. It must not spread those objects into `prepare`, deterministic methods, oneshot, common postchecks or public logs. Required agreements before integration:

1. **Exact schema and normalizer:** freeze schemaVersion, evaluationSchema, normalizerVersion, canonical `U_A` spelling, endpoint/check status definitions, and normalizer source hash. Uncertainty is interpreted by that policy, not `Boolean(array)` or an unreviewed row shortcut.
2. **Authentic receipt bytes:** identify which exact immutable bytes `binding.evidenceHash` binds (whole candidate evaluation receipt or endpoint envelope), serialization/encoding/version, independent storage/ref shape, and raw hash verification responsibility. Never hash a hand-assembled outcome summary and call it the original raw receipt.
3. **Pre-edit qualification:** bind baselineBundle to original source hash and exact frozen task/catalog/replay/checkpoint/viewport/observer/policy/compiler/runtime identities; give only opaque R/G eligibility and expected-key identifiers to trusted runner. No-op/unknown/nonworsening remain r3 owner decisions, not method support filters.
4. **Acceptance lock evidence:** define acceptanceLock fields, `acceptanceLockId`, independent persistence writer, time/order semantics and source/candidate/patch identity. Current runner boolean plus immutable in-memory snapshot is **not** a persisted r3 lock receipt. The bridge must persist a real locked decision before replay/evaluation and pass that exact artifact; it cannot invent a retrospective ID after seeing results.
5. **One replay, one proposal:** settle whether r3 `evaluateAcceptedR3` itself performs candidate replay. If so, runner's injected executor should hand over the independent locked replay request and evaluator invokes r3 once; it must not replay twice. If executor performs replay, r3 must accept those exact raw observations under a frozen contract. No retries, no alternate runtime, no private feedback to methods.
6. **Complete checks:** supply exact endpoint `expectedKeys` and key namespaces/masks; all checks map to the shared row-state protocol with explicit missing/blocked/notMeasured. Preserve raw temporal evidence/reasons/provenance alongside the projected rows. Missing/duplicate keys remain audit failures/unknown and cannot be dropped to match classification.
7. **Hash checks:** verify original hash equals archival UTF-8 source identity, candidate hash equals rebuilt patches/output, baseline original hash matches, r3 candidate hashes and acceptanceLockId agree, and endpoint eligibility matches the frozen pre-edit plan. Any mismatch is an integration audit error; accepted does not become rejected retroactively.
8. **Admitted execution:** source generation/model/browser calls remain disabled here. Parent's conditional pilot authorization only becomes executable after the combined method/domain/baseline/independence/safety/private/transport admission gates are signed. This interface work alone does not establish those gates.

No stub bridge or invented source/acceptance/evidence binding is supplied as a substitute for these answers. Actual runtime integration follows as a separately tested, versioned independent adapter after eval508 provides the precise public API.
